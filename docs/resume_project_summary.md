# Resume Project Summary

### FPGA-Based Vehicle Immobilization System
**Verilog | Nexys 4 DDR | Xilinx Vivado | FSM / Digital Logic**

- Developed a PIN-based FPGA security prototype on the Nexys 4 DDR using four hardware switches and a 16-LED status interface
- Implemented PIN comparison logic with `1010` as the authorized code and distinct LED patterns for authorized and unauthorized conditions
- Integrated the design with a Nexys 4 DDR XDC constraint file and structured the RTL into top-level and lock-control modules
- Contributed to testing and debugging of the digital design, as documented in the academic project report
